## 現在の仕様書と食い違っている点

2026-09-06〜07 の見直し（[docs/history.md](../docs/history.md)）で変わったもののうち、
これらの文書に古いまま残っている主なもの。

- **並列 CAM の AND** — スライド 03 は `match_flag[0] & match_flag[1] & match_flag[2]`（アレイ単位のフラグ AND）。
  現在は行ごとのマッチベクトル同士で AND する（仕様書 5 章）
- **「近傍」の意味** — 当時は「最小ビット差のエントリを優先」。現在はプレフィックス近傍と明記し、
  Morton コードと境界問題の扱いを定めている（6 章）
- **Write 時のマスク** — 当時は規定なし。現在は常に完全一致で判定（4 章 共通規則）
- **多重ヒット** — 当時は規定なし。現在は最小インデックス + `multi_hit`（6 章）
- **valid ビット、書き込みポインターの full** — 当時は無し / 効いていない。現在は 3 章・9 章
- **タイミング** — Write 3 クロック → 1 クロック。近傍検索 `(K+1)×2` → `(K+1)+1`（9 章）
- **RTL、BRAM 版 CAM、検索シーケンサー、FPGA 合成の実測** — 当時は存在しない
- **機密区分** — 企画書のヘッダーは「公開」。仕様書末尾の文言とは食い違ったままで、リポジトリは公開

作り直す予定はありません。企画書やスライドが必要になったら、仕様書から新しく起こします。
